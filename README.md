# CoolWindowsUtility
Чистит Компьютер от говна. Пофиг будет паблик

Что отключается

ИИ: Copilot, Recall, Click to Do, ИИ в Блокноте и Paint, боковая панель Edge с Copilot.
Телеметрия: минимальный уровень сбора данных, рекламный ID, CEIP, история действий, отчёты об ошибках, Bing-подсказки в поиске Пуска, автоустановка рекламных приложений.
Службы: DiagTrack и dmwappushservice отключаются, но не удаляются.
Задачи планировщика: только те, что собирают телеметрию (Appraiser, CEIP, Siuf).

Что не тронуто: Защитник, Центр обновления, брандмауэр, драйверы, Microsoft Store, сеть и сам Edge как браузер.

Как скрипт защищает систему

Точка восстановления: она создаётся перед изменениями.
Сохранение исходного состояния: значения реестра, типы запуска служб и список отключённых задач записываются в %ProgramData%\WinCleanAI\state.json. По -Undo всё возвращается. При повторном запуске сохранённое исходное состояние не перезаписывается.
Только политики и отключение: по умолчанию скрипт ничего не удаляет. Приложения удаляются только с флагом -RemoveApps, и это единственное, что -Undo не откатывает. Их можно поставить заново из Microsoft Store.
